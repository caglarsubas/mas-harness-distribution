# Security Policy

Report vulnerabilities privately through GitHub's security-advisory interface for this repository. Do not include tenant data, credentials, private keys, or production artifacts in an issue.

The distribution tool accepts only bounded local filesystem input. Remote URLs, symlinks, special files, mutable references, unverified blobs, unapproved source ports, and network fallback fail closed. Release signing, registry access, installation, and live runtime are outside DIST-001.
